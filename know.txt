
git status	                Shows modified files and staged changes.	Run this before every action. It prevents you from accidentally committing files or tracking the wrong code.
git diff	                Displays line-by-line code edits you made.	Allows you to double-check your code changes before saving them, catching mistakes early.
git stash	                Temporarily hides your dirty code edits.	Cleans up your workbench without losing work. Great when you need to change branches quickly.
git stash pop	            Brings back your hidden code edits.	        Restores the exact code you saved with git stash so you can continue working.
git restore <file>          Discards changes in a single local file.	If you break one file, this instantly reverts it back to its last safely saved state.
